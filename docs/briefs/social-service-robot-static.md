## 形状与坐标

原创、无品牌室内轮式服务机器人，完整资产 AABB **X宽0.55 × Y高1.20 × Z深0.65 m**，标注 `synthetic/assumed`。米制、+Y 向上、+Z 正面；完整包围盒底面中心为原点，Ymin=0，X/Z 中心为0。尺寸是本次视觉草稿工作假设，不是真实设备规格。

`service_robot_root` 下有平稳底盘、简洁机身、左右独立轮组 `wheel_left` / `wheel_right`；各轮组枢轴在真实轮心，候选轮轴沿局部 X，记录局部轴和中心。顶部 `sensor_cap` 与前方 `status_light_cover` 单独节点。名称只表示静态部件，不是已确认 subject kind、驱动接口或性能声明。

采用清楚的主体轮廓和可辨正面，使总览能识别、点击聚焦能看清轮组与分件；统一中性 PBR，不烘焙场景光影、状态色或网格文字，不要求发光扩展。不得复制品牌或他人几何。可观察公开人物/设备的整体风格，但具体参考须有可读来源及权利记录。

## 范围与验收

只做静态视觉母版，不是配送或清洁专用机器人；不增加托盘、清扫机构、机械臂或抓取能力。不做动画/rig、LOD、压缩、导航、碰撞或自主运行。状态灯只留独立灯罩；状态槽、socket 与真实传感器能力尚未确认，不猜绑定、不以空值伪装已知语义。

交付无损 `.blend`、无损 GLB、可重建源与依赖、README/制作记录、manifest/meta、尺寸节点轴和 truth、真实来源许可、逐文件字节/SHA256，以及官方 Validator 0 error 必要记录；未执行检查如实标明。母版不套 runtime 面数预算，不增加全行程功能审计；unused UV info 不构成返工。运行时 LOD/meshopt/KTX2 由平台派生，消费者场景视觉验收后才按治理流程激活。
