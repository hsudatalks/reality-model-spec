# 通用空气处理机组（AHU）静态母版 brief

本 brief 是原创通用合成设计规范，明确允许公开传播，并据此为本项目原创建模、修改和交付。它不包含客户参考或第三方源几何；此许可不覆盖客户导出 GLB、其他资产或仓库其他文档，不将其改授 CC0/MIT。

## 形状与坐标

完整资产 AABB X/Y/Z 为 **2.4×2.8×6 m**，标注 `synthetic/assumed`。米制、+Y 向上、+Z 正面及候选气流方向；进风口在 -Z，出风口在 +Z。完整包围盒底面中心为原点，Ymin=0，X/Z 中心为0。

`ahu_root` 下组织三个矩形机箱段：`filter_section`、`coil_section`、`fan_section`；名称仅为视觉分件候选，不是正式 kind 或功能契约。另含可独立隐藏的检修面板、进出风口框、独立 `fan_rotor` 和一块示意 `damper_blade`。叶轮合为一个节点，原点在实际中心，候选旋转轴为局部Z；示意风门原点在实际中心，候选轴为局部X。记录各段尺寸、节点中心、局部轴及假设。

## 范围与验收

只做静态视觉母版，不做实际流动、动画/rig、LOD、压缩、导航、碰撞或水冷管网；不捎带 FCU/VAV/RTU/DOAS。damper/valve/fan_speed 是消费需求词，不是已确认绑定：正式驱动、状态及 sockets 由消费方确认，不猜 schema 或未知值。

交付无损 `.blend`、无损 GLB、可重建源与依赖、manifest/meta、尺寸节点轴和 truth、真实来源许可、逐文件字节/SHA256，以及官方 Validator 0 error 必要记录。母版不套 runtime 预算，不要求全行程功能审计；unused UV info 不构成返工。
