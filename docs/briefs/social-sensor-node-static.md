# SOCIAL-SENSOR-NODE：通用传感节点静态母版

本 brief 是完整的原创合成设计，允许公开传播并用于本项目原创制作和交付。用途为 Apps 已有 SOCIAL P2 通用 sensor node 静态可视化；不指定厂家、传感测量类别、真实功能或已部署设备。公开文档不授予第三方资料许可，也不把资产改授 CC0/MIT；资产的公开及跨客户复用权仍为 pending。

## 静态造型与几何范围

- 完整可见尺寸为 X宽 **0.12 m** × Y高 **0.12 m** × Z深 **0.06 m**，**包含背部安装板**；尺寸为 synthetic/assumed，写入重建源码。只要求这一组尺寸，不扩大参数范围。
- 外形是方形、紧凑的通用传感节点外壳，浅壳体配前盖、非镜头式窗口和通风格栅。窗口采用平整方形或矩形盖片，不做镜头、镜筒或相机光学外形。区别于长筒相机和双天线网关；**不加天线**。
- 以下六个部件分别为独立、可辨识的 ASCII 语义节点：`mount_plate`、`body`、`front_cover`、`sensor_window`、`vent_grille`、`status_light_cover`。前盖朝 **+Z**；灯罩只表示静态几何及中性材质，不表示设备状态。安装板在背部，计入完整边界。
- GLB 单位为米，**+Y up、+Z forward**。完整可见几何 AABB 底面中心为原点，**Ymin=0**；目标包围范围为 X=[-0.06,0.06]、Y=[0,0.12]、Z=[-0.03,0.03] m。报告实际完整 AABB，不以壳体或前盖的局部边界替代。
- 仅按实际 GLB 几何记录背部安装面的中心坐标与法向，作为几何候选；不把它写成已确认 socket、现场安装锚点、安装适配或功能契约。

采用中性 PBR 和语义材质名；保持概览轮廓及近看部件清晰。无品牌、烘焙文字、场景光影或状态色。纯色材质可以不使用贴图；如使用贴图，须来源合法并在 GLB 内自包含。质量母版不设面数硬门槛。

本次仅静态源范围，不声明测量、采集、识别、无线或联网能力，不定义状态动作、动画或 rig，不制作或声明 LOD、meshopt/KTX2 等压缩运行时。平台派生和未来 kind/状态契约另行确认，不阻塞本次静态制作；静态外形不等于功能或消费验收。
