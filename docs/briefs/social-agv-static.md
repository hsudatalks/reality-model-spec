# 紧凑通用 AMR／AGV 静态母版 brief

本 brief 是原创通用合成设计规范，明确允许公开传播，并据此为本项目原创建模、修改和交付。不包含客户参考或第三方源几何；此许可不覆盖客户导出 GLB、其他资产或仓库其他文档，不将其改授 CC0/MIT。

## 形状与坐标

紧凑、无品牌室内移动机器人，完整资产 AABB **X宽0.8 × Y高0.6 × Z长1.2 m**，`synthetic/assumed`。这是静态视觉工作假设，不是厂家或现场真值；不承运 ISO40，不复用港口大型运输车外形。米制，+Y 向上、+Z 正面与候选行驶方向，完整包围盒底面中心原点（Ymin=0、X/Z中心为0）。

`amr_root` 下包含简洁低底盘、四个独立轮组、可视载荷顶板 `load_plate`，以及前方独立 `sensor_cover` 和 `status_light_cover`。轮组枢轴在实际轮心，记录中心及局部轴；记录候选顶板平面 Y 和尺寸。无驾驶室、机械臂或抓取。总览能识别轮廓，点击聚焦能看清轮组与顶板；原创中性 PBR，无品牌文字，不烘焙光影、状态色或文字，不要求发光扩展。

同一通用模型只供 charging/building/facility 的紧凑移动机器人角色复用；不覆盖 berth-demo/interactive-demo 岸桥旁的集装箱运输 AGV，港运车辆是独立需求。dock-allocation 是分配角色，不是另一种硬件 kind，不另造该外形；正式 subject kind 仍由消费方确认。充电坞是单独候选，不含在本模型中。

## 范围与交付

只做静态无损母版，不做转向动作、轮子动画、骨骼、LOD、压缩、导航、碰撞或真实自主运行能力。载荷、sockets、充电和状态槽契约待消费者确认，不猜接口。名称仅表示静态部件，不代表已支持驱动行为。

交无损 `.blend`、无损 GLB、可重建源与依赖、制作/交付文档、manifest/meta、实际尺寸与 truth、节点/枢轴/候选顶板平面、真实来源许可、逐文件字节/SHA256，以及官方 Validator 0 error 必要记录。母版不套 runtime 预算，不追加工艺或全行程验收；unused UV info 不构成返工。平台负责运行时派生与LOD，消费者反馈总览和聚焦画面。

只在具体任务既有授权入口交 DRAFT，不改分享权限或解除其他受阻操作。保留旧版本，更新自有制作/交付文档；每30分钟主动报到，完成/受阻立即报告。正式 Library 入库及激活按现有治理流程，不以 Drive 草稿冒充上架。
