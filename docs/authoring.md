# 母版制作

交付目标是可重建、比例正确的高质量母版。平台另行生成 runtime；不要为了 runtime 三角面预算减损母版。交付清单见[元数据与交付](metadata-and-delivery.md)。

## 坐标、尺寸与锚点

- 最终 GLB 使用米，**+Y up、+Z front**；尺寸顺序为资产坐标的 **X 宽 / Y 高 / Z 长**。
- 默认原点为底部接触面中心。人物采用脚底接触面底部中心；轨道设备可采用两轨着轨点中点，船体可采用水线中心，但特殊锚点必须在任务中明确，并确认消费及派生链路支持。
- 当前静态 ABI 参考的 `anchor` 仅支持 `bottom-centre`。特殊锚点的制作约定不意味着该输入入口已支持它；不得把特殊锚点错标为默认锚点。
- 接触面、轨距、挂点、轴与枢轴均用最终 GLB 坐标表述。消费引擎若采用不同内部前向，由消费端统一转换一次。
- 整理并应用必要变换，最终避免负缩放和非均匀缩放；保留有意设计的关节、层级及局部运动变换。

标称尺寸须附来源、版本和测量依据，并区分实测事实、标准/图纸依据、假设尺寸与合成视觉设计。`truth` 在制作说明中据实描述，不构造未经约定的 ABI 字段或枚举。未知尺寸列为待确认，不将虚构数据声明为项目真值。

尺寸检查默认累计 GLB 内部节点变换，在资产坐标中测量本资产几何包围范围；排除展示地面、外部场景和实例放置变换。注明测量对象与方法。本规范不增加统一尺寸容差；采用任务及消费契约确认的精度要求。

## 几何与材质

几何应干净，比例和轮廓正确，清除无关隐藏物、重复面和退化几何，保持朝外的正向法线。不要通过双面材质掩盖错误法线。保持必要的结构与细节，记录实际三角面、节点和材质统计。

采用统一调色板和可复用的 PBR 材质槽，槽位名称稳定且用途明确。材质表述物体本身的表面；不将场景光照、阴影、告警/状态颜色或文字烘焙进模型和贴图。文字与状态覆盖由消费端处理，不把标牌文字制作成文字网格。

基础格式遵循 [glTF 2.0 的节点、变换与材质定义](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html)；本规范的调色板、前向及交付要求是额外制作约定。

## 可动结构与可重建源

有动作需求时保留稳定命名的节点、父子层级、关节和枢轴，说明局部轴、初始姿态、运动范围及限位。源文件应能重建导出结果，不将可动部件错误合并为无法驱动的单一网格。实际需要哪些结构和动作，以[数据驱动动画契约](data-driven-animation.md)为准；没有动作范围时不自行增加动画义务。

必交无损质量 `.blend` 母版、无损 GLB，以及原始贴图、可重建源和全部必要依赖。无损指保留母版质量，不做 runtime 减面、量化、meshopt 压缩或有损贴图转码。记录制作/导出工具版本、导出设置、依赖来源和重建步骤；缺少或不能随包交付的依赖明确列出取得条件与权利。

作者文档、manifest 和元数据应随交付更新。GLB 与源文件的关系、已知差异及未支持能力须可追溯，不以“支持动画”一句话代替可验收说明。
