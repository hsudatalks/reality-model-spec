# 贡献与公开范围

本仓库是模型师共享材料与工具说明的统一公开入口。可贡献通用规范、任务/验收模板、公开工具说明，以及有明确公开和再分发权利的参考资料。新增资料应在 [README](../README.md)或[工具索引](../tools/README.md)可发现，记录来源、适用版本及能力限制；优先链接官方资料，不整页复制第三方内容。

## 可以公开什么

- 与具体客户和项目无关的制作原则、ABI 参考说明与虚构示例。
- 不含私有语义、数据和操作配置的可复用模板。
- 官方工具下载/使用链接；拥有公开权利的原创工具说明或轻量本地 helper。
- 经确认可公开并具有合法授权的参考材料；公开可访问不自动等于可再分发。

本仓库不通过通用规范给模型或第三方资料重新授权。贡献者说明实际来源与权利，不冒用他人作者身份，不将未确认权利写成开放许可。真实资产交付按任务约定进行，不上传到这里。

## 不得提交的内容

私有模型、源包、贴图/渲染图、真实交付或检查报告、用户资料及客户数据；私有项目标识、人员名单、Drive 私有链接/文件 ID、内部线程或收件路径；账号配置、token、cookie、密码、密钥、证书及 credentials；主机地址、用户绝对路径、服务端口、部署命令和私有服务配置；平台私有入库/派生实现。

仅在当前独立公共仓库中贡献，不通过改变已有私有仓库的 visibility 或 origin 分享材料。示例使用虚构资产名、相对路径和示意数据；不得嵌入实际账号或网络端点。

## 一次必要的提交检查

提交前查看改动文本与精确文件清单，确认链接、版本和示例一致，检查是否含上述私有信息或秘密。只暂存明确要公开的文件，不使用无关的全目录暂存。新增 helper 如适用，用一个小样本验证其声称的能力即可；说明它不能替代官方 Validator、平台入库或场景验收，不引入网络访问或凭证依赖。

根目录 `.gitignore` 排除常见秘密、本地私有目录、账号配置、模型与归档包；忽略规则只防止常见误暂存，不能代替查看实际提交范围，已跟踪文件也不会因此自动被排除。不要用强制添加绕过这些规则。

每次变更记录文档版本与 CHANGELOG。生产者使用时固定本规范的版本/commit，以及工具、资产和消费契约的确切版本。未确认接口写明待确认，不将说明稿声明为已实现能力。
