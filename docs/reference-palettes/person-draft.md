## 显式值与格式默认值

- 五槽均显式声明 `doubleSided: true`，且均显式声明上表三个 PBR 参数。
- 五槽均未声明 `alphaMode`（glTF 默认 `OPAQUE`）、`alphaCutoff`（默认 0.5，仅 MASK 模式有意义）或 `emissiveFactor`（默认 `[0,0,0]`）；这些默认值不是作者显式写入的字段。
- 五槽均没有 base-color、metallic-roughness、normal、occlusion 或 emissive 贴图引用；材质内未声明扩展。不能据此声称在任意照明下得到相同截图。
- 未重跑 Validator、渲染或人体尺寸检查；本表不证明实时渲染与 Cycles 一致。
