# 数据驱动状态与动画

本页是任务与验收要求，**不是已实现的 JSON 绑定接口**。通用母版暴露可复用的结构与动作能力，项目数据字段到能力的绑定属于消费侧；不将某个项目字段硬编码进通用母版。

先声明任务适用性：静态、已确认动态、动态候选待契约。静态资产的内部动画标为 **N/A（本次无内部动画要求）**；场景中的位置、朝向及实例控制属于消费端，不因此推定母版需要 clip 或骨骼。

## 复杂/可动资产任务必填表

每个 slot 分别填写，不用“支持动画”代替以下内容。没有证据的项在任务文档中写“待确认”，不可把占位文本写进 GLB ABI。

| 项目 | 必须给出的内容 |
| --- | --- |
| 真正可用的消费者 | 使用场景、播放器/引擎版本或 commit、消费契约及 state-slot/schema 的 URI 与版本/commit/SHA pin；注明实现与实测状态 |
| 输入状态槽 | 准确名称、来源、类型、单位、范围或枚举、采样频率；没有已确认 slot 时不自行命名为正式接口 |
| 生命周期 | 初始、缺失、过期、重置各自的行为；有效期或判断条件；区分无数据与真实零值 |
| 驱动映射 | 输入到稳定节点、关节或 clip 的对应关系，父子层级，输入→位移/旋转/pose 的规则 |
| 机械约束 | 局部运动轴、枢轴、单位、初始姿态、限位与动作范围，均对应最终 GLB 结构 |
| 执行方式 | 直接 transform、clip 播放或 scrub 等已确认方式；不默认支持蒙皮或 morph |
| 时间行为 | 时间基准、播放/暂停、采样/插值、seek、回放与复位；迟到或乱序数据处理依消费契约 |
| 状态表现 | 机械动作与状态色、文字、告警分开列出；覆盖由消费端实现，记录需保留的材质槽 |
| 派生保留 | 必须保留的节点/层级、枢轴、clip/动画及 ABI；各 LOD 同输入下动作一致，切换不跳变 |
| 场景验收 | 固定输入→预期 pose/状态；边界、缺失、过期、重置、seek 与 LOD 切换用例；固定资产/数据/引擎 pin 与场景证据 |

该表不定义 slot 的 wire format、GLB 绑定字段或未知值 schema，也不规定尚未确认的动作执行协议。具体绑定结构必须来自真实消费者契约。

## 最小验收记录模板

| 用例 | 固定输入/时间序列 | 预期节点或 pose | 实际结果与证据 |
| --- | --- | --- | --- |
| 初始状态 | 待消费契约确认 | 待确认 | 未测 |
| 正常与范围边界 | 待消费契约确认 | 待确认 | 未测 |
| 缺失/过期 | 待消费契约确认 | 待确认 | 未测 |
| 重置/seek/回放 | 待消费契约确认 | 待确认 | 未测 |
| 相同输入跨 LOD 切换 | 待消费契约确认 | 姿态连续且符合约定 | 未测 |

场景记录应固定实例数量、机位、硬件、分辨率及材质/实例化/LOD 策略，附可重现输入、截图和所需 fps、p95 帧时、内存、draw calls 等证据；指标阈值由消费场景给出。没有执行的项写“未测”，不写通过。

## 推进边界

未确认动态契约不阻塞已授权的参考研究或静态几何阶段；相关运动结构和绑定的最终制作以确认后的范围为准。缺少消费 pin 或行为验收的复杂动画资产不能标为可直接场景使用。

当前静态派生路径不证明动画保真支持。动态派生须确认节点、动画、蒙皮/morph（如需）及跨 LOD 行为均能保留；不能以几何预检成功代替行为验收。详见 [runtime 能力边界](runtime-and-lod.md)。

## 参数化设备与生产流程

按[参数化设备](parametric-equipment.md)把上述每设备表连接到参数文件、生成源和输出的 SHA：区分几何参数、候选动作能力与已实际消费状态。参数变化应联动节点、局部轴/枢轴、限位与接口候选点；每个动作记录其真实 source/type/unit/range、初始/缺失/过期行为、时序映射及派生保留。没有正式消费契约就列 owner 待确认，不在 ABI 新造 slot。

GLB 提供几何/节点，工序调度与数据逻辑归消费端；Library 以精确版本、digest/provenance 检索。静态 PASS 不等于动态可用。FACTORY-INV1 的实际契约 path/commit 待交付后填写，研究 ETA 不作为已实装证据。

先由 delivery 最终选择、验收一条短链，以可重放 **ASSUMED TEST** 正常及停机/故障恢复数据，覆盖上游交出→本机进料/在制/动作反馈→出料/质量分流→下游接收与反馈；含缺失/过期/复位/seek 及现有消费能力内的 LOD 节点保真。未获项目工艺确认时不预设完整真实顺序或物料字段。截图/PBR 不足以证明闭环；不新增运行接口/全类别动态硬门槛，也不要求已完成静态母版整批重做。
