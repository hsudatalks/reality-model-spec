# 模型任务模板

以下是任务文档模板，不是可导入的绑定 schema。`example-crate@0.1.0` 仅为虚构标识示意；填写时采用作者确认的实际资产身份，不沿用示例权利或数据。

| 项目 | 填写内容 |
| --- | --- |
| 资产与版本 | 作者确认的 assetId、assetVersion、kind；文档规范版本/commit |
| 本次范围 | 静态 / 已确认动态 / 动态候选待契约；明确本批要交付的能力 |
| 消费依据 | 使用场景、消费者版本/commit、契约/schema URI 与固定版本或 SHA |
| 尺寸与 truth | X 宽/Y 高/Z 长，单位米；出处、测量方法、事实与假设的区分 |
| 坐标与锚点 | GLB +Y up/+Z front；默认底部中心或明确特殊锚点及链路支持情况 |
| 接触/轨距/挂点 | 适用事实、GLB 坐标、契约依据；未知项列待确认，不造 ABI 默认值 |
| 视觉与材质 | 可追溯风格参考、统一调色板/PBR 材质槽、轮廓与质量要求 |
| 来源与权利 | 实际 author/source/license/reuse_rights/provenance；依赖权利及取得条件 |
| 可动能力 | 静态内部动画 N/A，或完整填写下方动画要求 |
| 母版交付 | `.blend`、无损 GLB、原始贴图/依赖、可重建说明、manifest/元数据 |
| 文件证明 | 每文件相对名称、bytes、SHA-256；作者版本与本批可交接声明 |
| 轻量检查 | 格式报告及输入 pin、元数据/尺寸/锚点证据、确定性预检结论；未执行项据实标记 |
| runtime 目标 | 消费场景选择档位和实例数量；平台派生，不把预算套到母版 |
| 验收与反馈 | 固定资产/数据/引擎/场景；草稿结果、待确认项和生产者需修改项 |

复杂/可动资产必须附[数据驱动动画必填表与输入→pose 验收表](../docs/data-driven-animation.md)，包含真实 state-slot/schema pin、类型/单位/范围、生命周期、节点/关节/clip 映射、局部轴/枢轴/限位、时间与插值、派生保留及跨 LOD 一致性。

待确认表建议采用“事项｜缺少的证据或契约｜影响的能力/阶段｜当前可推进范围”。这仅是文档记录方式，不是 GLB unknown schema。未定复杂动作契约不阻塞获准静态范围；静态草稿必要检查通过后推进下一步，正式 active 仍须消费验收。

交付标准：[母版制作](../docs/authoring.md)、[元数据与交付](../docs/metadata-and-delivery.md)、[runtime 与 LOD](../docs/runtime-and-lod.md)。
